# security — 网络安全线

安全方向的技能：代码审计、漏洞分析、协议与流量、实验环境搭建。

Security-focused skills: code review, vulnerability analysis, protocol and traffic work, lab environments.

## 状态

规划中。这个分支目前只有结构，还没有可用的技能。

## 已确定的选题方向

| 方向 | 大致内容 | 备注 |
|---|---|---|
| 源码审计 | 给定代码库，按语言特性定位危险函数与可控输入 | 优先 Java / PHP，与后端线交叉 |
| 反序列化漏洞 | 从 gadget chain 到利用链的分析路径 | 需要沙箱约束，只在授权环境内演示 |
| Web 漏洞复现 | 按 OWASP 分类复盘常见漏洞的成因与修复 | 强调"为什么会错"，不是"payload 怎么编" |
| 日志与流量分析 | 从 pcap 和访问日志里还原攻击链 | 输出时间线与证据链，可复现 |

## 一条提前定下的边界

安全类技能一律**只在授权场景内工作**：用户自己的靶场、CTF 题目、明确授权的测试目标。遇到要求攻击真实第三方系统的请求，拒绝并说明理由，不提供部分帮助来"绕过"。

这条不写在某个技能里，写在整条分支的约定上——因为安全技能最容易在细节上失守，边界必须前置。

## 交叉点

和后端线共享 Java 生态的知识（Spring、Shiro、JNDI），和教育线共享文档写作能力（漏洞报告的写法接近学术报告：结论先行、证据可定位、影响范围要说清）。
