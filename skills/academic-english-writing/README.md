# academic-english-writing

英文学术写作技能，覆盖**写、评、教、考**四个场景。

A skill for English academic writing, operating in four modes: drafting, grading, teaching, and exam sprint.

---

## 什么时候会用到它

| 你会这样说 | 它做什么 |
|---|---|
| "帮我写一篇关于 X 的 essay，800 词" | 收窄选题 → 出提纲 → 写正文 → 给改稿说明 |
| "帮我把这段 introduction 改一下" | 改语言和衔接，保留你的论点 |
| "帮我写个 abstract" | 按五要素公式写，不写"本文将……"式的目录腔 |
| "这篇能拿多少分？" | 五维打分 + 三处改进 + 知识点归因 |
| "老师说我论证不足，哪里不足？" | 定位到具体段落，指出缺的是证据还是解读 |
| "APA 格式怎么排？" | 文内引用与参考文献条目，逐条对照 |
| "这段话算抄袭吗？" | 判断是改写、拼贴还是抄袭，给改法 |
| "讲讲什么是 thesis" | 诊断你的水平后，只讲你缺的那一层 |
| "带我练一下 topic sentence" | 出题 + 只给第一步 + 验收 |
| "三天后要交论文，怎么救" | 按剩余时间倒排计划 + 保命句型 + 失分点 |

技能会自动识别模式，不需要你点名。只有一种情况它会反问：你说"帮我看看这篇"，它要先确认你要**打分**还是要**直接改**——这两件事产出的东西完全不同。

## 四个模式各给什么

### A 写作

按 `选题 → 论点 → 提纲 → 分节起草 → 引用 → 修改` 推进。写作顺序刻意是非线性的：先写主体，再写结论，最后写引言和摘要——因为引言要交代"这篇文章实际上写了什么"。

每个主体段必须满足 PIE：**主张**（带观点的主题句）、**证据**（带出处）、**解读**（这个证据怎么支持主张）、**衔接**。第三项是最常缺失、也最扣分的一项。

### B 批改

100 分量表：

| 维度 | 分值 | 看什么 |
|---|---|---|
| 论点与内容 | 25 | 是否可争议、是否全文贯穿、是否有独立判断 |
| 结构与组织 | 20 | 段落功能、unity、过渡、首尾呼应 |
| 证据与论证 | 20 | 证据相关性、是否解读、反方处理、逻辑跳跃 |
| 语言 | 25 | 语法准确、句式变化、学术语体、用词精确 |
| 格式与引用 | 10 | 标题摘要、参考文献、文内引用、字数、排版 |

反馈固定六段：一句话总评 → 分数表 → 三处最值得改 → 知识点归因 → 下一步练习 → 一句具体的肯定。

第三条（三处最值得改）是重点：每处都给**原文摘录、问题类型、为什么扣分、单句示范、预期提分**。只给前三项是判决，给全五项才是教学。

### C 教学

先诊断，再讲。三个探针：让你写一句你要论证的话、指出这段里哪个句子是主张、解释你为什么引这句话。从结果判断你卡在哪一层，然后**只讲那一个点**。

每节课的结尾必须是一个能检验的练习——检验标准是"看输出"，不是"问你懂了没"。

附 11 条常见误解。比如"引用越多越显得读过书"、"高级词汇等于学术水平"、"结论要写新想法才有深度"。这些信念不点破，讲多少规则都会反弹。

### D 速通

按剩余时间分四档：7 天、3 天、1 天、3 小时，只给对应那一档。

它会在开头告诉你一个可能不爱听的事实：**速通能把你从 60 多分推到 80 多分，推不到 90+。** 90 分那档要原创角度，模板给不了。这个上限写死在技能里，不会为了让请求者高兴而放宽。

优先级排序：`论点清楚 > 段落有主张 > 每处证据有解读 > 引用格式齐全 > 语言漂亮`。多数人时间全花在最后一项，那是性价比最差的分配。

## 安装

```bash
# 用户级：所有项目可用
cp -r skills/academic-english-writing ~/.workbuddy/skills/

# 项目级：只对当前项目生效
cp -r skills/academic-english-writing <repo>/.workbuddy/skills/
```

或者打包成 zip 从导入入口安装：

```bash
zip -r academic-english-writing.zip academic-english-writing/
```

导入器认的是**压缩包或文件夹**。单独上传一个 `.md` 会报"没有找到 SKILL.md"——不是 YAML 的问题，是它在压缩包里找文件。

## 硬规则

这 11 条优先于任何风格偏好和使用者要求。以下是其中最重要的五条：

1. **不编造文献、作者、年份、页码、DOI。** 需要引用但没有来源时，留 `[CITATION NEEDED: 需要什么来源]`。
2. **不编造数据。** 缺数字就留 `[DATA NEEDED: ...]`，不用含糊量词糊过去。
3. **改写不得是拼贴。** 换同义词而保留原句结构属于抄袭。连续六个词与原文相同即视为不合格（专有名词、术语、加引号的直接引用除外）。
4. **不放大原文立场。** 原文说 *suggests*，不许写成 *proves*。
5. **不为了让用户高兴而抬分。** 分数要能从量表推出来。

另外六条涉及批改不代写、教学不代做、修改要透明、术语要沿用、不确定性要标注、不协助规避查重。

## 知识来源

结构与技能划分参照外研社引进版《学术英语论文写作》（*Writing Research Papers*, Dorothy E. Zemach / Daniel Broudy / Chris Valvona / 高霄，Macmillan Writing Series L4）的 12 个单元。引用规范按 APA 第 7 版；教材示例基于旧版，以 APA 7 为准。

教材没覆盖的部分由本技能补齐：中文母语者的语言干扰、IMRAD 各节的具体写法、以及评分与教学的方法。
