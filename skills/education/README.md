## 这一线的选择标准

教育类技能和别的领域不一样：它必须**承认自己的判断有边界**。写作没有唯一正确答案，评分带有主观成分。所以这里的技能都遵守两条额外规矩：

1. **分数要能推出来。** 每一次扣分都要指到具体句子，同一份作业评两次不会差出 10 分。
2. **不许替学习者完成。** 批改只给示范句，教学只给第一步，剩下的留给他自己做——否则技能越强，学习者越退步。

这两条写在每个技能自己的硬规则里，不依赖使用者的自觉。
